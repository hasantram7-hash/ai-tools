# Collection of Ram 🚀

**Collection of Ram** is an all-in-one suite of 22+ everyday tools, creator utilities, productivity instruments, and smart digital helpers built entirely in Kotlin and Jetpack Compose.

---

## 📱 About The App

- **App Name**: Collection of Ram
- **Package ID**: `com.aistudio.collectionofram.pk`
- **Developer / Creator**: Hem Narayan (@hem-narayan)
- **Design System**: Material Design 3 (Dark Titanium & Electric Rose)
- **Monetization**: Google AdMob Banner Integration

---

## ✨ Features & Included Tools

### 🛠️ Everyday Essentials
- **Smart Calculator & Unit Converter** (Currency, Weight, Length, Temperature)
- **Quick Notes & Sticky Checklist** with instant local persistence
- **World Clock & Timezone Converter**
- **Habit Tracker with Daily Streaks**
- **Stopwatch & Multi-Interval Timer**

### 🎨 Creator & Social Media Studio
- **YouTube Thumbnail Previewer & Studio**
- **Viral Reel / Shorts Hook Generator**
- **Social Media Bio & Caption Formatter**
- **Aesthetic Fake Tweet & Quote Generator**
- **Tag & Hashtag Optimizer**

### ⚡ Smart Productivity
- **Strong Password Generator**
- **QR Code Creator & Scanner**
- **Text Utilities & Word Counter**
- **Color Palette & Gradient Designer**
- **Device & Connection Speed Monitor**

---

## 📦 Download & Installation

You can install the ready-made `.apk` directly from:
- **`app/src/main/assets/CollectionOfRam.apk`**
- Or from releases on GitHub / APKPure / Uptodown.

---

## 🛠️ Tech Stack
- **Language**: Kotlin 2.0+
- **UI Framework**: Jetpack Compose & Material Design 3
- **Local Persistence**: Room Database & Android DataStore
- **Ads SDK**: Google Mobile Ads SDK (AdMob)
- **Architecture**: MVVM with unidirectional data flow
